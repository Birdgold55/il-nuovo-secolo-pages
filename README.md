# Il Nuovo Secolo — sito informativo

Sito in italiano dedicato a **Il Nuovo Secolo**, server Discord di roleplay politico ambientato nel 1920. Presenta l’ambientazione, i passaggi per iniziare, la struttura dei canali, le informazioni su partiti e movimenti, una sintesi delle regole e le risposte alle domande frequenti.

Il sito è una pagina statica (`index.html`), senza dipendenze o passaggi di build. GitHub Pages è configurato per pubblicare la cartella principale del branch `main`.

URL pubblicato: <https://birdgold55.github.io/il-nuovo-secolo-pages/>

I collegamenti per entrare nel server e seguire il progetto sono nel sito. Il sito è informativo e non ufficiale; per il regolamento aggiornato fa fede il canale `regole` su Discord.
